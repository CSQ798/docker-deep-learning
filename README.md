# 深海与木箱 · Docker 深度学习手册

一套为**零基础大一新生**写的 Docker 深度学习材料。它不追求"三天速通"，
而是用十三章、约 27 万字正文，把 Docker 从**为什么存在**讲到**如何进入真实工程与 AI 场景**，
并在此过程中训练学习方法本身。

---

## 怎么打开

最简单的方式：**双击 `index.html`**，用浏览器打开即可。全部内容都在本地，
不需要联网、不需要安装任何东西、不需要起服务器（术语解释内嵌在页面里）。

如果你习惯用命令行，也可以在你的电脑上起一个静态服务（推荐，路径与缓存表现更干净）：

```powershell
# 在本文件夹里执行
python -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

> 建议用 Chrome / Edge / Firefox 的较新版本。本手册依赖少量现代 CSS 与 JavaScript，
> 但即使脚本被完全禁用，所有正文、章节结构、链接与术语总表内容依然可读。

## 阅读方式

1. **从 `index.html` 的"学习地图"进入**，按 00 → 12 的顺序读。这不是并列的知识点，
   而是一条因果链，跳读会让你只记住命令而得不到理解。
2. **正文里带点状下划线的词都可以点击**，会弹出它的英文缩写、英文全称、中文释义与详细解释。
   顶部按钮可以关闭这些下划线（如果你觉得干扰），也可以调整字号。
3. **每一章末尾的"自测题"答案折叠在题目下方**，请先自己回答再展开；
   后面的"自问自答"故意不给答案，因为答案只能从你嘴里出来。
4. **动手做每一个实验**。所有命令都能在 Windows + Docker Desktop（WSL2 后端）+ PowerShell 下执行。

## 设计与内容纪律

- **四色体系**：深墨 `#16232e`、灰蓝 `#5b6b7a`、青蓝 `#1f5f74`、冷白 `#f4f6f8`。无第五种颜色。
- **字体**：正文宋体（Windows 用 SimSun 系列，macOS 用 Songti SC），代码用等宽字体。
- **背景**是冷灰蓝，不是米白或暖色。
- **完全离线**：没有外部 CDN、字体、图片或统计脚本；所有链接都是可选的外部延伸阅读。
- **每章包含**：学习目标、技能清单、6—9 个正文小节、回望/前瞻/方法论/易错点/比喻/思考块、
  10—14 道带折叠答案的自测题、8—10 道自问自答、总结、拓展资源与书单。
- **正文合计约 27 万汉字**，每章不少于一万字。

## 维护脚本

需要 Node.js 18+（本机已用 Node 22 验证）。

```powershell
node tools/check.js            # 校验全部章节的结构与字数
node tools/check.js ch05       # 只校验某一章
node tools/check-html.js       # 检查标签配对、未知 class、编码
node tools/check-terms.js      # 校验术语库：重复、冲突、字段完整性
node tools/check-autolink.js   # 预览正文会被自动加下划线的词
```

`tools/` 下还有几个一次性修复脚本（`fix-both.js` 规范 Markdown 加粗、
`fix-bold.js` 修复反向加粗、`rebuild.js` 从会话日志重建文件版本），
保留它们是为了让这份材料可以被继续维护，而不是只此一版。

## 关于这份材料的用法建议

如果你读到这里，说明你可能打算真的把它读完。那么有一句话值得放在前面：

> 这份材料能给你的最大帮助，不是让你记住 Docker 的命令，
> 而是让你在某一刻忽然发现——**你开始能够自己推理一个陌生系统的行为了**。

请慢一点。允许自己在一章里停很久，允许自己合上页面去动手，允许自己暂时不懂。
真正会长在你身上的东西，从来不是被读完的，而是被想通的。
